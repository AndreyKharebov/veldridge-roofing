# Настройки анимаций

## Два файла для изменения скорости

- `src/styles/motion/_settings.sass` — длительности, задержки, расстояния, easing,
  hover, масштабирование фотографий, меню, аккордеоны и модальные окна.
- `src/config/motion.js` — порог видимости, rootMargin и таймеры каруселей.

Sass использует секунды (`0.56s`) и пиксели (`28px`). JS использует миллисекунды
(`5000` = 5 секунд). `threshold` — доля площади элемента от 0 до 1 (`0.15` = 15%).

## Где что менять

| Задача | Параметр |
|---|---|
| Появления About, Services, Gallery, Blog | `--motion-reveal-duration` |
| Расстояние выезда | `--motion-reveal-distance` |
| Шаг последовательного появления | `--motion-reveal-stagger` |
| Характер движения | `--motion-reveal-easing` |
| Кнопки, ссылки, Read More, фильтры, поля | `--motion-color-duration` |
| Hover Latest News на главной | `--motion-news-hover-duration` |
| Hover карточек Gallery | `--motion-project-hover-duration` |
| Увеличение фото при наведении | `--motion-image-zoom-duration`, `--motion-image-zoom-scale` |
| Окно проекта / статьи | `--motion-dialog-duration`, `--motion-dialog-distance` |
| Затемнение за модальным окном | `--motion-backdrop-duration` |
| FAQ и мобильный WhyChooseUs | `--motion-accordion-duration` |
| Иконка FAQ | `--motion-accordion-icon-duration` |
| Мобильное меню / бургер | `--motion-menu-duration` |
| Переход фотографий Home Hero | `--motion-hero-crossfade-duration` |
| Появление отзывов | `--motion-testimonial-duration` |
| Частота автопереключения Hero И отзывов | `motionConfig.carousel.intervalMs` |
| Первая смена Home Hero | `motionConfig.carousel.heroInitialDelayMs` |
| Порог запуска появления | `motionConfig.reveal.threshold` |

В `_settings.sass` сначала идут настройки Desktop, затем Tablet (701–1100px)
и Mobile (до 700px). При изменении Desktop проверь, нет ли отдельного значения
в адаптивном разделе. У Header свой существующий breakpoint: 767px.

Contact переопределяет общий профиль внутри `.contact-page` в том же файле.
У Home отдельные группы `--motion-home-hero-*`, `--motion-home-about-*`,
`--motion-home-services-*`, `--motion-home-benefit-*`. Они не наследуют скорости
внутренних страниц. Исходные Home-задержки сохранены **и на узких экранах**:
Services — 0 / 0.08 / 0.16s; WhyChooseUs — 0 / 0.1 / 0.2 / 0.3s.
Чтобы убрать их, переопредели соответствующие `*-delay` на `0s` в нужном media.
Hover Services на Home по-прежнему наследует длительность и задержку появления.
Это перенос управления, а не изменение ранее согласованного темпа.

Пример: чтобы сделать появления внутренних страниц медленнее на Desktop,
измени `--motion-reveal-duration: 0.56s` на `0.7s`. Чтобы переключать обе
карусели каждые 7 секунд, измени `intervalMs: 5000` на `7000`.
Интервал карусели и длительность визуального перехода — разные параметры.
Для проверки новой конфигурации JS перезагрузи страницу; уже завершённые
появления сами не перезапускаются. CSS-переменные можно временно изменять
в DevTools, сохраняя окончательный вариант в `_settings.sass`.

## Как устроено

`_animations.sass` содержит общий reveal, варианты Home и общие keyframes.
Он и настройки подключены **один раз** через `src/styles/main.sass`.
Локальные Sass-файлы сохраняют стили компонентов и hover/focus-селекторы,
но все ненулевые длительности используют центральные CSS-переменные.
Позиционные transform (например, центрирование иконки) не являются анимацией
и остаются в вёрстке.

`src/hooks/useMotionReveal.js` обслуживает все шесть страниц. Сценарии находятся
в `src/pages/<Page>/motion/<page>Motion.js`: selector, direction, stagger,
offset, columns/tabletColumns. Объекты сценариев должны быть стабильными
(объявлены вне компонента), иначе эффект будет заново подключаться при рендере.
Длительностей в этих файлах нет.

Gallery включает наблюдение за добавлением карточек и запоминает их стабильные
ID до ухода со страницы. Contact исключает форму, ошибки и результат из анимации.
Модальные окна анимируются только при открытии, без задержки закрытия и эффектов
на абзацах. Hover и scroll reveal карточек Gallery остаются на разных элементах.

Видимость: `pending` → `visible`; `static` показывает сразу при фокусе,
якорном переходе или отключении движения. Каждый элемент появляется один раз
за посещение. Resize, открытие модального окна и ввод в форму не сбрасывают
состояние. Новое посещение страницы начинает сценарий заново.

При Reduced Motion или недоступных API наблюдения контент виден сразу.
При включении Reduced Motion во время просмотра незавершённые эффекты
заканчиваются и не перезапускаются после обратного переключения. При печати
все уже смонтированные элементы показываются. Общий хук очищает наблюдателей,
события и requestAnimationFrame при unmount и в React StrictMode.

Политики автопрокрутки сохранены: Home Hero начинает смену через фиксированный
initial delay и не ждёт Insurance; отзывы пропускают скрытую вкладку и не
запускаются при исходном Reduced Motion. Унификация этих политик не входит
в этот рефакторинг. Новых зависимостей и изменений контента нет.
